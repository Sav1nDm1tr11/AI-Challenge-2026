# Веса финального ансамбля

Распакуйте `final_assets.zip` в корень проекта: появится `artifacts/final/`.
Архив содержит замороженную DINOv2, три patch-головы, визуальный baseline, геометрическую модель и validation-предсказания для всех трёх сравнений.
Контрольные суммы перечислены в `configs/assets.json`.

При наличии прямой ссылки notebook скачивает архив из `MESH_ASSETS_URL`.
Ссылка появится после публикации release-архива владельцем репозитория.
